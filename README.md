# draw2guess

一个模仿 Steam 游戏 **Draw & Guess** 的开源多人你画我猜接龙项目。玩家轮流作画、猜词，一条题目按固定队列传完整圈，最后一起复盘每一棒被理解成了什么。

项目使用 Python 标准库编写后端，前端为原生 HTML/CSS/JavaScript，不需要 Node 构建，也不需要第三方 Python 依赖即可本地运行。

## 主要功能

- **接龙画猜**：4–16 人房间，所有玩家随机排成一个固定队列圈，整局都按同一顺序传递；每人一条题目链，偶数人时每人各留一棒，奇数人时少一棒，保证最后一棒一定是猜词。
- **账号与恢复**：注册登录后使用 HttpOnly Cookie 保持 30 天会话；换设备登录同一账号会自动回到原房间和原席位；房主长时间离线时自动迁移房主权限。
- **掉线处理**：12 秒无心跳即全员暂停 40 秒，房主可延长或提前结束；未返回的席位被跳过，最后一份有效内容继续传给下一位，不给接龙补空白。
- **绘画工具**：近全屏画纸，6 种笔触（标准、马克笔、铅笔、毛笔、蜡笔、喷枪），3 个图层，不透明度，数位板压感，自选双色渐变，填充，线条橡皮与普通橡皮，撤销与清空。
- **自动复盘**：回放、匹配投票、题主评选全部由服务端按时间推进，所有玩家同步观看。每幅画按笔画顺序逐笔绘制出现，匹配票达到 75% 才算完整传递；题主选出最佳画作后进入下一条链，全部结束后统一计分。
- **作品库**：每局自动保存回放 demo，可逐条观看或模拟观战；画作可收藏到个人画廊，画廊内置画室可继续编辑或新建作品。
- **茶绘**：等待页提供多人同步画板，所有人同时绘画，但只能操作自己的线条；可隐藏指定玩家的笔迹，收藏时只保存当前可见内容。
- **题库**：独立的共享词库页面，支持搜索、分页、批量添加、去重、导出；开局要求题库超过 50 个词条，且同一局为所有玩家抽取的题目互不重复。
- **声音**：准备倒计时、提交、揭晓、匹配等提示音，以及独立的 BGM 与音效音量设置。

## 技术栈

- Python 3.10+，标准库 WSGI 应用
- SQLite（WAL 模式）存储题库、房间、画作、回放与画廊
- 原生 HTML / CSS / JavaScript，Canvas 绘制
- 生产环境可选 Gunicorn，多进程多线程运行

## 本地运行

```bash
python app.py --port 8088 --seed
```

打开 http://127.0.0.1:8088 。词库页面在 `/`，游戏入口在 `/game`，作品库在 `/library`。

常用参数：

```bash
python app.py --host 0.0.0.0 --port 8088 --db data/huacai.sqlite3 --seed
```

数据库默认写入 `data/huacai.sqlite3`，该目录不纳入 Git。`--seed` 仅用于首次创建示例题库。

## 测试

```bash
python -m unittest discover -s tests -v
node --test tests/test_game_recovery.cjs
```

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `app.py` | WSGI 入口、题库与账号接口、静态资源白名单 |
| `game.py` | 房间状态机、接龙逻辑、复盘、画廊与茶绘 |
| `static/` | 词库页、游戏页、作品库页及前端脚本 |
| `deploy/` | systemd 单元、安装与备份脚本、依赖 wheel 安装器 |
| `tests/` | 后端集成测试与断线恢复测试 |
| `docs/` | 部署与维护说明 |
